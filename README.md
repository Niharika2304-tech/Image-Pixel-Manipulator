 Image Pixel Manipulator using NumPy

Project Overview
This project demonstrates image creation and pixel manipulation using Python, NumPy, and Matplotlib in Google Colab.

Features
- Synthetic RGB image creation using `np.zeros()` and `np.full()`
- Image cropping and horizontal/vertical flipping
- RGB channel extraction
- Brightness adjustment
- Bright-pixel detection using Boolean masking
- Memory comparison between `uint8` and `float64`
- Real-image processing using a Kaggle dataset
- Additional negative, grayscale, and threshold filters

Technologies Used
- Python
- NumPy
- Matplotlib
- Google Colab
- Kaggle

How to Run
1. Open the `.ipynb` notebook in Google Colab.
2. Run the cells in order.
3. Upload a suitable image or dataset when required.
4. View the outputs for each image-processing operation.
